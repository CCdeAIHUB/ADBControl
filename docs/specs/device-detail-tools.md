# 设备详情工具交互规格

## 终端

- 终端采用单一命令表面，提示符、用户输入和返回结果显示在同一控件中，不提供独立命令输入框。
- 多行 `TextBox` 会内部处理 Enter；终端必须以 `handledEventsToo: true` 注册 `UIElement.KeyDownEvent`，确保 Enter 和 Accept 都触发当前命令。
- 空命令不执行；执行期间输入只读，完成或失败后始终恢复提示符、焦点和历史索引。
- 上、下方向键浏览历史，光标不得编辑当前提示符之前的输出。

## 文件列表

- 文件列表使用 `InteractiveSurface` 自绘悬停、按下和选中背景。
- 文件夹的主题绿色和不同文件类型的前景色属于内容语义，交互表面不得递归覆盖这些前景色。
- 离开悬停、取消选中或重复进入页面后，图标颜色必须一致，不依赖重建页面恢复。

## 验收

- 终端 Enter 路由和文件图标前景保持有源码契约测试，桌面 Release 构建无警告。
- 真机验证时至少执行一条只读 shell 命令，并在列表中连续悬停文件夹与普通文件检查颜色稳定。
